# Security Policy

If you believe you have discovered a security vulnerability involving the LightBurn REST API, authentication system, or related software, please report it privately.

Do not publicly disclose security vulnerabilities before giving LightBurn Software a reasonable opportunity to investigate and address the issue.

Reports should include:

- A description of the issue
- Steps to reproduce
- Software version
- Operating system
- Relevant logs or screenshots
